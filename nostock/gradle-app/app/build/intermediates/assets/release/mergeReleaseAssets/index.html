免责声明（必读）
本应用（「戒股」）是一款个人行为记录工具，仅用于帮助用户记录自己戒除股票交易的天数、冲动时刻与交易行为。

本应用 不提供任何投资建议，不推荐任何股票、不承诺任何收益，不构成任何投资或医疗行为。股市有风险，入市需谨慎。

本应用内容不构成对"炒股成瘾"或任何心理/精神健康问题的诊断、治疗或替代。如你认为自己有相关困扰，请联系专业医生或心理咨询机构。

一、收集哪些信息

只收集你主动填入的记录：打卡日期、冲动时刻的触发点与感受、交易的标的金额盈亏、以及提醒设置。

所有数据只保存在手机本地，卸载即清除。不收集姓名、手机号、设备 ID、位置、相机、相册、联系人，不发起任何网络请求。

二、权限说明

  • 震动：打卡完成时的轻反馈，可随时在系统设置关闭。
  • 网络：仅 WebView 壳的技术兼容性，当前版本无实际网络请求。
  • 不申请相机、麦克风、相册、位置、通讯录、存储读取等。

三、第三方 / 数据导出

不集成任何第三方分析、推送或归因 SDK。你可以在「设置」里导出 JSON 备份或一键清空全部数据。

四、完整条款

完整版本以本应用随附的 privacy.html 为准，或访问应用内设置页底部的链接查看。
