戒股 · 隐私政策与免责声明

最后更新：2026-11-16

免责声明（必读）
本应用（「戒股」）是一款个人行为记录工具，仅用于帮助用户记录自己戒除股票交易的天数、冲动时刻与交易行为。

本应用 不提供任何投资建议，不推荐任何股票、不承诺任何收益，不构成任何投资或医疗行为。股市有风险，入市需谨慎。

本应用内容不构成对"炒股成瘾"或任何心理/精神健康问题的诊断、治疗或替代。如你认为自己有相关困扰，请联系专业医生或心理咨询机构。

一、我们收集哪些信息

本应用只收集 你主动填入的记录，并且 只保存在你的手机本地。
我们 不 收集：姓名、手机号、微信号、身份证号、设备 ID、位置、相机、麦克风、相册，不读取你的联系人、短信、通话记录。

具体的记录内容

  • 打卡记录：你在首页点击"今天我忍住了"的日期与时间
  • 冲动记录：你主动填写的诱惑金额、触发原因标签、当时感受、备注文字
  • 交易记录：你主动填写的交易标的、金额、盈亏、下单原因、事后感受
  • 应用设置：提醒开关、演示模式（如果有）、备份导入

存储方式

所有数据存放在你手机操作系统为应用分配的私有存储中（Android 的 data 目录，受沙箱保护）。卸载应用会一并删除全部数据。

关于网络

当前版本 不发起任何网络请求。应用的离线版本不访问互联网。应用内"每日一句"为本地预置文案，不通过网络拉取。

二、权限使用说明

本应用申请以下系统权限，仅为以下用途：

VIBRATE（震动）分析完成时提供震动反馈；可随时在系统设置关闭。
INTERNET（网络）仅用于 WebView 壳的技术兼容性；当前版本无实际网络请求。

不申请、不使用相机、麦克风、相册、位置、通讯录、存储读取等权限。

三、第三方服务

本应用不集成任何第三方分析 SDK、归因 SDK、推送 SDK 或统计 SDK。没有任何第三方服务可以访问你的数据。

四、数据导出与删除

你可以在应用内「设置」页面一键把所有记录导出为 JSON 备份，也可以一键清空全部数据。卸载应用同样会彻底删除所有本地记录。

五、未成年人使用

本应用不面向未满 18 周岁的未成年人。如你是未成年人，请先与监护人沟通，不要在没有指导的情况下参与股票交易。

六、变更与联系

本政策如有更新，会在应用内设置页或通过相同 URL 发布新版本。如你对本政策有任何疑问，请通过应用内提供的联系方式与开发者取得联系。
