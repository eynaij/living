```
戒股是一款纯本地的自我记录工具，用来帮你把「不买」练成习惯。

【它做什么】

· 统计：本月打卡热力图、连续天数走势曲线、近 8 周冲动频次柱状图。
· 每周复盘：周一打开自动弹出上周报告——打卡几天、冲动几次、交易几笔、亏了多少。

【它不做什么】
· 不推荐股票，不预测涨跌，不提供任何投资建议。

· 没有广告，没有内购订阅，没有推送轰炸。

【隐私】
所有内容保存在设备本地存储。你可以随时在设置里导出 JSON 备份，或一键清空全部数据。应用内「隐私政策 / 免责声明」可随时查看。

【适合谁】
想控制交易频率、想看清自己情绪化交易模式、想给自己一段「不动手」的时间的人。

【免责声明】
本应用仅为个人行为记录工具，不构成投资建议，也不能替代医疗或心理诊疗。如你感到无法自控，请寻求专业帮助。
```

## 4. 上传步骤（手动，最稳）

1. Play Console → 所有应用 → **创建应用**
   - 名称：戒股
   - 默认语言：中文（简体）
   - 应用或游戏：应用
   - 免费或付费：免费
   - 接受声明
2. 左侧「测试」→ **内部测试** → 创建新版本 → 上传 `jiegu-v1.0.0.aab`
   - 填写版本说明（见 `submission/release-notes.txt`）
   - 保存 → 审核 → 发布（内部测试无需谷歌审核，几分钟即可用）
3. 「设置」→ 应用完整性 → 应用签名：确认已启用 **Play 应用签名**（默认开启，Google 会重新签名，你的 keystore 作为上传密钥）
4. 补齐「应用内容」全部问卷（第 3 节）
5. 「商店设置」→ 商店信息：填写名称、简短说明、完整说明，上传图标 / 特色图片 / 截图
6. 内部测试通过后 → 关闭测试 → **封闭测试**（新个人账号必须：至少 12 名测试者，连续 14 天）
7. 14 天后 → 申请正式发布 → 提交审核（通常 1–3 个工作日）

### 新账号的硬性门槛
Google 从 2023 年 11 月起要求**个人开发者新账号**先做封闭测试：**≥12 名测试者，连续 14 天**，才能申请生产环境权限。这一步无法跳过。

## 5. API 自动上传（可选）

见 `scripts/upload-google-play.sh`，需要：
- Google Cloud 项目开启 *Google Play Android Developer API*
- 服务账号 JSON 密钥
- 在 Play Console → 用户和权限 中把服务账号邮箱加为「发布管理」权限

凭据准备好后运行：
```bash
bash scripts/upload-google-play.sh internal
```
