## 1. 应用介绍（长篇 · 200–500 字）

**标题（应用名）**：戒股

**一句话简介**（8–12 字）：不碰股票，先戒贪

**简短介绍**（80–120 字）：

「戒股」是一款专门帮你记录「不碰股票」这件事的个人工具。每天点一下，连续天数实时可见；冲动时刻写一笔，让自己看到诱惑的模式；真的下单了也不怕，把亏损记下来，让数字替你疼。数据全部在你手机本地，不需要注册账号，也不会上传到任何服务器。让时间替你战胜贪婪。

**详细介绍**（300 字左右，应用宝/华为/小米要求）：

「戒股」帮助你建立一个长期、清晰、没有外界干扰的个人记录系统，让自己清楚地看见：自己离"不再被股市牵着走"还有多远。

**核心功能**：
- **连续天数**：首页中央醒目标出你已经连续多少天没碰股票，历史最长、总清醒天数一眼可见。每过一天，数字 +1。
- **冲动记录**：差点动手的那一刻，记录下诱惑金额、当时被什么触发、内心感受是什么。次数多了你会看到模式——是朋友晒单？还是睡前刷手机？
- **交易墙**：真的下单了也可以诚实记一笔。累计真实亏损在头顶红色大字显示，让数字替你疼。
- **本月热力图 & 趋势图**：今天有没有打卡、最近 8 周冲动次数是涨是跌、连续天数是拉长了还是又断掉，一张图看清。
- **每周复盘**：周一自动弹出上周报告，帮你回看一周发生了什么。
- **本地存储**：没有账号、没有联网、没有广告、没有推送。所有数据都在你的手机里，可以一键导出备份或清空。

**免责声明**（必须放在介绍末尾或审核备注里）：
本应用是个人行为记录工具，不提供任何投资建议，不推荐任何股票，不承诺任何收益。内容不构成对"炒股成瘾"或任何心理/精神健康问题的诊断、治疗或替代。如你认为自己有相关困扰，请联系专业医生或心理咨询机构。
