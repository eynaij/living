使用说明

1. 摆放手机

把手机放在身体侧前方 2–3 米，镜头与腰同高，让持拍手一侧朝向镜头。全身（头到脚）都要入镜。

2. 选择球路

训练页顶部可切换高远球 / 正手挑球 / 反手挑球；持拍手和灵敏度在「设置」里调整。如果挥拍没有被识别，把灵敏度调高。

3. 挥拍

做一次完整挥拍：准备 → 引拍 → 击球 → 随挥。每次挥拍结束后会自动出分，结果会存入「记录」，可离线查看历史趋势。

评分怎么看

  • 高远球：重点看引拍屈肘、击球点高度、击球伸展、随挥幅度、屈膝蓄力、躯干前倾。
  • 正手挑球：重点看击球点是否在腰膝之间、击球伸展、屈膝蓄力、随挥向上、挥拍速度。
  • 反手挑球：与正手挑球类似，更强调低点击球和向上随挥。
  • 每项指标越接近目标区间分数越高，低于 72 分会出现在纠正建议里。

安装到主屏幕

Android / Chrome：点浏览器菜单里的「安装应用」或「添加到主屏幕」。iPhone / Safari：点底部分享按钮，选择「添加到主屏幕」，之后从桌面打开即可全屏使用。

隐私

所有画面与数据只在你的手机本地处理，不上传服务器，也不录制视频。
